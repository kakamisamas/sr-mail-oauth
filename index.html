sanctions-radar-mail

sanctions-radar-mail is a personal, single-user tool. It is not offered to the public.

It uses the Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly to read one dedicated mailbox owned by the operator. That mailbox only subscribes to official government sanctions and export-control e-mail bulletins (for example from the U.S. Treasury, the UK government and the U.S. Bureau of Industry and Security). The tool turns those bulletins into an internal compliance news digest.

Privacy Policy

  • Who uses it. Only the operator, on the operator's own Google account.
  • What is accessed. Messages in the operator's dedicated mailbox, read-only. The tool never sends, modifies or deletes mail.
  • How it is used. Messages that match the configured government senders are parsed into short records (subject, date, body text and the official link) for the operator's internal digest. Non-matching messages are ignored and not stored.
  • Storage. Parsed records are stored in the operator's private repository. Full raw messages are not stored. OAuth tokens are kept only in the operator's private environment.
  • Sharing. Data is not sold, not shared with third parties and not used for advertising or to train models.
  • Google API Services User Data Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.
